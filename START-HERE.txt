HOW TEST MODE WORKS
On the new repo's domain, a DESIGN PREVIEW strip appears automatically.
Buy Product and cart checkout show your selection in a preview dialog.
This mode does not charge customers, create Stripe sessions, link Discord,
or submit admin login emails/forms. Discord ticket links still open Discord.
Instant account stock is labelled STOCK ON LIVE STORE, without invented stock.
Public product controls and reviews use your existing Supabase connection;
if the review feed is unreachable, the included real featured reviews display.

The complete admin/order/account delivery files are included, but backend
actions are not part of this visual test. Existing Edge Functions and auth
redirects are configured for your live domain. Preview checkout does not test
Stripe webhooks, account-delivery emails, or Supabase writes.

On liquidlab.shop or www.liquidlab.shop, preview mode automatically turns off
and the existing payment/auth/stock integrations run normally. The Halloween
theme itself requires no database changes. Instant delivery still depends
on completing its previously supplied backend/email setup.
